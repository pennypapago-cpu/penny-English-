# 英文卡片

手機用的英文單字與句子練習網頁，只有自己用、不需要帳號、不用付費。

## 功能

- **新增卡片**：單字、片語或句子，可以記中文意思、看到的原句、出處和筆記。英文和中文都能用說的輸入。
- **每日複習**：看中文、開口說英文，系統會標出和答案不同的字，再按「忘了／模糊／記得」，自動安排下次複習時間（間隔重複）。複習時可以直接編輯卡片。
- **中文怎麼說**：說出想表達的中文，一鍵複製問題到 Claude，把回答貼回來，挑一句存成卡片。
- **連續播放**：不用翻卡，中文唸 1 次、英文唸 3 次，自動換下一張，適合運動時聽。播放時螢幕會保持開著。
- **備份**：資料只存在手機瀏覽器裡，請定期在「設定與備份」匯出備份檔。

## 使用方式

1. 在 GitHub 的 Settings → Pages，把 Source 設成 `main` 分支的根目錄。
2. 用手機打開 `https://pennypapago-cpu.github.io/penny-English-/`。
3. 加到主畫面（iPhone：Safari 分享 → 加入主畫面；Android：Chrome 選單 → 加到主畫面）。

## 技術

純 HTML、CSS、JavaScript，不需要編譯。語音使用瀏覽器內建的 Web Speech API，資料存在 localStorage。
